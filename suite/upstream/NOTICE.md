# Upstream provenance

The AsynCodeBench execution profile data and task/image references are from the
[official pinned release source](https://github.com/KaituoZhang/AsynCodeBench/tree/2a639b049f249e79eb2031876bc06a110be9ac3a).
The source license is [Apache-2.0](AsynCodeBench-LICENSE.txt). The original
scenario files, repository snapshots, task patches, tests and images are
retrieved from their original sources. They are not redistributed here.

The Pro manifests contain only selection metadata, public instruction features
and hashes. See [Scale's licensing information](https://huggingface.co/datasets/ScaleAI/SWE-bench_Pro#license)
for the evaluator and source repositories. Model weights, images, credentials,
private judge material and agent workspaces are external inputs.
